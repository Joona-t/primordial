  <name>Task 1: Build LangGraph integration harness with mock checkpointer and StateGraph</name>
  <files>tools/langgraph_integration_harness.py</files>
  <action>
    Create a LangGraph integration harness simulating the StateGraph + checkpointer architecture:

    1. MockCheckpointSaver class implementing the BaseCheckpointSaver interface:
       - put(config, checkpoint, metadata, new_versions) -> stores checkpoint in-memory dict
       - put_writes(config, writes, task_id) -> stores pending writes
       - get_tuple(config) -> retrieves checkpoint by thread_id + checkpoint_id
       - list(config, filter, before, limit) -> yields checkpoint history
       - get_next_version() -> generates incremental version IDs
       - Stores data in a dict keyed by (thread_id, checkpoint_id)

    2. ForgeCheckpointSaver wrapper class:
       - Wraps any MockCheckpointSaver (or real BaseCheckpointSaver)
       - Delegates ALL calls to inner checkpointer
       - On each put(), ADDITIONALLY registers the checkpoint as a forge artifact via LangGraphForgeAdapter
       - Captures: node name from metadata["source"], step from metadata["step"], state snapshot
       - Must NOT alter the checkpoint data or return value

    3. MockStateGraph class:
       - add_node(name, fn) -> registers node functions
       - add_edge(src, dst) -> fixed transitions
       - add_conditional_edges(src, condition_fn, mapping) -> conditional routing
       - compile(checkpointer) -> returns MockCompiledGraph
       - State is a TypedDict-like dict with typed fields

    4. MockCompiledGraph class:
       - invoke(input_state, config) -> runs the graph: START -> nodes -> END
       - For each node: call node_fn(state) -> checkpoint via put() -> route to next
       - Conditional edges: call condition_fn(state) -> route based on mapping
       - Skipped nodes (conditional edge routes past them): register absence via adapter

    5. LangGraphForgeHarness class:
       - instrument(graph, adapter) -> wraps graph's checkpointer with ForgeCheckpointSaver, wraps node functions
       - run_scenario(scenario_spec) -> executes a scripted graph execution

    6. Scenario specifications (at least 5 built-in):
       a. linear_pipeline: 3 nodes in sequence (planner -> executor -> reviewer), all produce output
       b. conditional_routing: planner node -> condition -> either executor or fallback, one path skipped
       c. tool_use_graph: agent node calls tools via tool nodes, mixed success
       d. error_recovery: node raises exception, graph handles with error node
       e. long_conversation: 10-node graph simulating multi-step task with checkpoints at each step

    Use ONLY stdlib + existing forge tools. No LangGraph import needed.
    Each scenario exercises checkpointer put/get, conditional routing, and absence detection.
  </action>
  <verify>
    1. All 5 scenarios run to completion without errors
    2. Each scenario produces a sealed chamber with validate_chamber() returning 0 errors
    3. ForgeCheckpointSaver.put() delegates correctly: inner checkpointer stores identical data
    4. Scenario b (conditional_routing) registers absence for the skipped branch node
    5. Scenario d (error_recovery) registers typed absence (invalid) for the failed node
    6. Checkpoint provenance: each node's artifact refs the previous checkpoint
  </verify>
  <done>LangGraph integration harness with 5 scenarios all producing valid sealed chambers. ForgeCheckpointSaver transparently wraps inner checkpointer.</done>
</task>
