  <name>Task 2: Build Measurement Framework and Structured Logging Baseline</name>
  <files>tools/baseline_measurement.py, tools/structured_logging_baseline.py</files>
  <action>
    Build two interconnected tools:

    A. MEASUREMENT FRAMEWORK (tools/baseline_measurement.py):

    The measurement framework orchestrates running tasks across all three baseline tiers and collecting comparable metrics.

    Functions to implement:

    1. run_task_uninstrumented(task_spec) -> dict:
       Run a task with the vanilla (uninstrumented) runtime.
       Returns: {task_id, tier, raw_output, token_count, duration_ms, errors}
       This produces the BASE-01 measurement.

    2. run_task_structured_logging(task_spec) -> dict:
       Run a task with the structured logging baseline (from structured_logging_baseline.py).
       Returns: {task_id, tier, raw_output, token_count, duration_ms, errors, spans, schema_violations}
       This produces the BASE-02 measurement.

    3. run_task_forge_instrumented(task_spec, adapter) -> dict:
       Run a task with the forge adapter (from Plan 02-02).
       Returns: {task_id, tier, raw_output, token_count, duration_ms, errors, chamber}
       This produces the forge measurement.

    4. collect_metrics(uninstrumented_result, structured_result, forge_result) -> dict:
       Compute all 5 canonical metrics from CONVENTIONS.md #7:
       - reachability_fraction: compute_reversibility_score(chamber) from forge result (0 for uninstrumented/structured)
       - compression_ratio: encode_trace(chamber) size / original chamber size (N/A for uninstrumented/structured)
       - vs_vanilla_pct: (forge_size - vanilla_size) / vanilla_size * 100
       - detection_rate: violations_detected / total_violations (per tier)
       - false_positive_rate: false_alarms / clean_runs

    5. bootstrap_ci(values, confidence=0.95, n_resamples=10000) -> (lower, upper):
       Compute bootstrap confidence interval for small samples.
       Uses numpy for resampling.

    6. persist_results(results, output_dir) -> None:
       Save all raw data + computed metrics to JSON files in output_dir.
       Include: raw results per run, per-task metrics, aggregate metrics with bootstrap CIs.

    ORDER-OF-MAGNITUDE ESTIMATES (for verification):
    - Uninstrumented: detection_rate expected ~0, reachability expected 0 (no provenance)
    - Structured logging: detection_rate expected > 0 but < forge (schema validation catches some)
    - Forge: detection_rate expected approaching 6/6 MockLM ceiling (ref-mock-experiment anchor)
    - Forge: reachability expected > 0, approaching 1.0 for non-compacted tasks

    B. STRUCTURED LOGGING BASELINE (tools/structured_logging_baseline.py):

    The intermediate baseline that adds standard observability WITHOUT forge features.

    MUST INCLUDE:
    1. Event recording: Log each agent turn and tool call with timestamps
    2. Schema validation: Check LLM responses for expected JSON structure (required fields present, types correct)
    3. Timing: Start/end timestamps, duration per turn and tool call
    4. Token counting: Track input/output token counts per LLM call
    5. Error recording: Catch and log exceptions, HTTP errors, timeouts

    MUST NOT INCLUDE (these are forge-specific features that defeat the purpose of the intermediate baseline):
    - Typed absence states (no AbsenceState enum, no normalize_absence_state())
    - Provenance DAG (no source_refs, no parent_id linkage)
    - Hash-verified trace compression (no encode_trace/decode_trace)
    - Structural violation detection (no validate_transition, no null discipline checks)

    Implementation: Use Python's logging module with structured JSON output. If opentelemetry-api and opentelemetry-sdk are available, use OpenTelemetry spans. If not, use a lightweight custom span implementation (dict-based with start/end/attributes). Do NOT add a hard dependency on OpenTelemetry -- make it optional.

    SEPARATION CHECK: After writing, verify that structured_logging_baseline.py has ZERO imports from forge_nulls, forge_chamber, forge_trace_codec, or forge_reversible_summary. This is the acceptance test test-structured-logging-distinct.
