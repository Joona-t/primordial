  <files>tools/compaction_harness.py</files>
  <action>
    Create `tools/compaction_harness.py` with the following components. This harness measures provenance survival through LLM context-window compaction events.

    IMPORTANT: All code must use ONLY Python stdlib + numpy + scipy. Do NOT use networkx (not installed). Implement BFS with stdlib collections.deque.

    1. **CompactionSnapshot dataclass:**
       - timestamp: str (ISO 8601)
       - artifact_ids: list[str] (all artifact IDs in the chamber at snapshot time)
       - content_hashes: dict[str, str] (artifact_id -> SHA-256 hash of canonical JSON content)
       - ref_graph: dict[str, list[str]] (artifact_id -> list of artifact IDs it references via source_refs)
       - stage_count: int
       - Build from a forge chamber dict: `CompactionSnapshot.from_chamber(chamber: dict) -> CompactionSnapshot`
       - The content hash for each artifact is computed as: `hashlib.sha256(json.dumps(artifact, sort_keys=True, ensure_ascii=True).encode()).hexdigest()`

    2. **Three-tier ref classification function:**
       ```
       def classify_refs(pre: CompactionSnapshot, post: CompactionSnapshot) -> dict:
       ```
       For each ref in the post-compaction snapshot:
       - resolved: ref target exists in post snapshot AND content hash matches pre-compaction hash
       - degraded: ref target exists in post snapshot BUT content hash differs from pre-compaction hash (content was lossy-summarized)
       - broken: ref target does NOT exist in post snapshot (artifact was removed by compaction)
       Return: `{"resolved": [...], "degraded": [...], "broken": [...], "total": int, "structural_reachability": float, "semantic_fidelity": float}`
       Where: structural_reachability = (resolved + degraded) / total, semantic_fidelity = resolved / total
       Handle edge case: if total == 0, both metrics = 1.0 (no refs to break)

    3. **BFS reachability function (stdlib only, no networkx):**
       ```
       def measure_reachability(snapshot: CompactionSnapshot) -> dict:
       ```
       Build adjacency list from snapshot.ref_graph. Identify root nodes (artifacts with no outgoing refs, i.e., iteration-0 artifacts). BFS from EVERY artifact toward roots. An artifact is "reachable" if BFS from it reaches at least one root. Use `collections.deque` for BFS queue.
       Return: `{"reachability_fraction": float, "reachable_count": int, "total_count": int, "unreachable_ids": list[str], "max_depth": int}`
       Verify: reachability_fraction = reachable_count / total_count, in [0.0, 1.0]

    4. **Simulated compaction function (Approach 2 fallback):**
       ```
       def simulate_compaction(chamber: dict, deletion_fraction: float, seed: int = 42) -> tuple[dict, CompactionSnapshot, CompactionSnapshot]:
       ```
       Takes a forge chamber and programmatically deletes the oldest `deletion_fraction` of stages (by index order, since stages are chronologically ordered). Creates pre-deletion and post-deletion snapshots. Returns (modified_chamber, pre_snapshot, post_snapshot).
       Deletion removes stages AND their artifacts from the artifact_index. Source refs to deleted artifacts become broken.
       This provides a LOWER BOUND on reachability under real compaction (random deletion is worse than intelligent summarization).

    5. **Violation detection regression function:**
       ```
       def violation_regression(chamber: dict, fault_types: list[str] = None) -> dict:
       ```
       Reuse FaultInjector from tools/fault_injector.py. For each fault type in [D1, D2, D5, D9] (the types Phase 3 detected at 100%): inject fault, run validate_chamber(), check if detected.
       Return: `{"per_type": {type: {"injected": bool, "detected": bool}}, "regression_passed": bool, "types_tested": int, "types_detected": int}`
       regression_passed = True if all 4 types still detected.
       Default fault_types = ["D1", "D2", "D5", "D9"].

    6. **Compaction measurement pipeline function:**
       ```
       def run_compaction_measurement(chamber: dict, deletion_fractions: list[float] = None) -> dict:
       ```
       Orchestrates the full measurement for a single chamber:
       a. Take pre-compaction snapshot
       b. Measure pre-compaction reachability (should be 1.0 per Phase 2)
       c. For each deletion_fraction in [0.3, 0.5, 0.7]:
          - Simulate compaction
          - Measure post-compaction reachability
          - Classify refs (resolved/degraded/broken)
          - Compute degradation = pre_reachability - post_reachability
       d. Run violation regression on the original (non-deleted) chamber
       e. Compute trace compression via encode_trace/decode_trace from forge_trace_codec.py
       f. Return complete measurement dict with all metrics, CIs, and anchor comparisons

    7. **Bootstrap CI integration:**
       Import and reuse `bootstrap_ci` from tools/baseline_measurement.py (B=10000, seed=42).
       Import and reuse `clopper_pearson_ci` and `select_ci` from tools/fault_injector.py.

    8. **Anchor comparison function:**
       ```
       def compare_against_anchors(measurements: dict) -> dict:
       ```
       Compare post-compaction metrics against:
       - MockLM ceiling: reachability=1.0, compression=87%
       - Phase 2 baseline: reachability=1.0, compression=1.18x, depth=21
       - Backtracking threshold: reachability=0.5
       Return gap analysis dict with each comparison documented.

    Include ASSERT_CONVENTION line at top of file:
    ```python
    # ASSERT_CONVENTION: natural_units=N/A, compaction_layer=LLM_context_window, reachability=BFS_fraction, hash=SHA-256_canonical_JSON
    ```

    Do NOT use `_fake_count_tokens` from MockLM -- this is explicitly PROHIBITED by the research.
    Do NOT conflate forge trace compression with LLM context-window compaction.
    All uses of "compaction" must be qualified (LLM compaction vs forge compression).
