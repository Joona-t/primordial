  <name>Task 1: Build summary parser for LLM compaction output</name>
  <files>tools/summary_parser.py, tools/test_summary_parser.py</files>
  <action>
    Create `tools/summary_parser.py` with the following capabilities:

    1. **extract_artifact_ids(text):** Find all forge artifact IDs matching `artifact:[a-zA-Z0-9_:.-]+:r\d+` in free text. Must handle:
       - IDs embedded in prose ("The artifact:run100:stage:builder:r1 was created...")
       - IDs in brackets ("[PROVENANCE: artifact:run100:stage:builder:r1]")
       - IDs in code blocks (```artifact:run100:stage:builder:r1```)
       - Near-misses that should NOT match (e.g., "artifact_id", "artifact:incomplete")
       - Return deduplicated list preserving order of first occurrence.

    2. **extract_source_refs(text):** Find mentions of provenance relationships in summary text:
       - Explicit: "source_ref: artifact:X -> artifact:Y" or "derived from artifact:X"
       - Implicit: "Based on [artifact:X]" or "extending artifact:X"
       - Return list of (source_id, target_id) tuples where identifiable, or (source_id, None) for unresolved.

    3. **extract_state_labels(text):** Find mentions of absence states from V1_ABSENCE_STATES:
       - Match: "state: not_generated", "marked as deleted", "pruned_recoverable"
       - Import V1_ABSENCE_STATES from forge_nulls.py for canonical state list.
       - Return dict mapping state_name -> count of mentions.

    4. **parse_summary_provenance(text):** Unified function that calls all three extractors and returns a structured dict:
       ```python
       {
           "artifact_ids": [...],
           "source_refs": [...],
           "state_labels": {...},
           "provenance_density": float,  # artifact_mentions / total_tokens
       }
       ```

    5. **classify_ref_tier(artifact_id, summary_text, original_content, similarity_fn):** Classify a ref as resolved/degraded/broken per protocol Section 5.3:
       - **Resolved:** ID in summary AND similarity(original, summary_excerpt) > 0.9
       - **Degraded:** ID in summary BUT similarity < 0.9 (content paraphrased)
       - **Broken:** ID NOT in summary

    NOTE: The existing `extract_artifact_ids()` in `compaction_experiment.py` is minimal (regex only). This module provides a more robust version with deduplication, context extraction, and integration with the ref classification pipeline. The `compaction_experiment.py` version should eventually delegate to this module.

    Create `tools/test_summary_parser.py` with:
    - 10 synthetic summary texts covering all extraction edge cases
    - Tests for near-miss rejection (no false positives)
    - Tests for paraphrased/reformatted IDs
    - Tests for classify_ref_tier with all three tiers
    - Tests for provenance_density calculation
    - At least 15 test functions total
  </action>
  <verify>
    1. All tests pass: `python3 -m pytest tools/test_summary_parser.py -v`
    2. Precision of extract_artifact_ids = 1.0 on test corpus (zero false positives)

    4. extract_state_labels correctly identifies all 8 V1_ABSENCE_STATES when present in text

<task type="auto">
  <name>Task 2: Build embedding similarity module with graceful fallback</name>
  <files>tools/embedding_similarity.py, tools/test_embedding_similarity.py</files>
  <action>
    Create `tools/embedding_similarity.py` extending the existing `semantic_provenance_fidelity.py`:

    1. **EmbeddingSimilarity class:**
       - Primary backend: `sentence-transformers` with `all-MiniLM-L6-v2` model
       - Fallback backend: token overlap from `semantic_provenance_fidelity.py` (when sentence-transformers unavailable)
       - Auto-detect backend on init; log which backend is active
       - `compute_similarity(text_a, text_b) -> float`: Returns cosine similarity (embedding) or Jaccard similarity (fallback)
       - `compute_batch(pairs: list[tuple[str, str]]) -> list[float]`: Batch computation for efficiency

    2. **tier_classify(similarity: float) -> str:** Classify into three tiers per protocol Section 5.3:
       - similarity > 0.9 -> "resolved" (near-exact preservation)
       - 0.7 <= similarity <= 0.9 -> "degraded" (paraphrased but semantically intact)
       - similarity < 0.7 -> "broken" (significant information loss)
       - Return tier name as string.

    3. **calibrate_thresholds(pairs: list[tuple[str, str, str]]) -> dict:** Given labeled calibration pairs (text_a, text_b, expected_tier), compute actual similarity for each and report:
       - Whether default thresholds (0.7, 0.9) correctly separate the tiers
       - Recommended threshold adjustments if misclassification occurs
       - This is for post-Track-A recalibration.

    4. **Integration with SPFMetric:** Add a `from_embedding_similarity(cls, sim: EmbeddingSimilarity)` classmethod to SPFMetric that uses the embedding backend instead of token overlap.

    NOTE: `sentence-transformers` is currently MISSING from the environment. The module MUST work with only the token overlap fallback. The embedding backend is optional and should be enabled when the dependency is installed. Test both paths.

    - At least 12 test functions total
