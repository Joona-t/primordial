  <files>tools/xarch_analysis.py, data/xarch/analysis_results.json</files>
  <action>
    Build the analysis module that produces the RQ4 verdict:

    1. XArchAnalysis class:
       - __init__(ag2_data_path, langgraph_data_path, coverage_gaps_path)
       - load_data() -> parses JSONL campaign files
       - per_framework_aggregate(framework) -> dict with:
         * session_count
         * validation_errors: total, per_session_mean
         * reversibility: mean, std, min, max
         * trace_verified_pct: fraction with hash_match=True
         * violation_count, violation_rate, cp_95_upper (Clopper-Pearson)
         * absence_events: total, per_session_mean
         * compaction_events: total, per_session_mean
         * per_scenario_type breakdown
       - cross_architecture_comparison() -> dict:
         * Side-by-side metrics for AG2 vs LangGraph
         * Delta (absolute and relative) for each metric
         * Consistency assessment: "equivalent" if within 10%, "divergent" otherwise

    2. Anchor comparison methods:
       - compare_to_mock_experiment() -> dict comparing each framework against MockLM:
         * MockLM reversibility=1.0 vs framework mean
         * MockLM trace integrity=100% vs framework pct
         * MockLM violation detection=6/6 vs framework violation rate
       - compare_to_openclaw() -> dict comparing each framework against OpenClaw baseline:
         * OpenClaw reversibility=1.0 vs framework mean
         * OpenClaw validation_errors=0 vs framework total
       - compare_to_phase7() -> dict:
         * Phase 7 violation rate (0/211, CP upper 1.73%) vs per-framework violation rate
         * Consistency check: are cross-architecture results within Phase 7 bounds?

    3. Verdict logic:
       - render_verdict() -> dict with:
         * verdict: "POSITIVE" | "PARTIAL" | "NEGATIVE"
         * qualification: "pipeline-validated, pending live validation"
         * evidence: specific metrics supporting verdict
         * POSITIVE criteria: BOTH frameworks achieve reversibility >= 0.95,
           0 validation errors on clean sessions, 100% trace integrity,
           cross-architecture consistency within 10%
         * PARTIAL criteria: one framework meets all criteria, other has gaps
         * NEGATIVE criteria: neither framework meets criteria
       - CC-014 assessment: does the result satisfy the multi-architecture requirement?
       - CC-015 carry-forward: prevention framing consistent with Phase 7?

    4. Forbidden proxy audit:
       - Check fp-mock-as-real: verdict must carry qualification
       - Check fp-hide-gaps: coverage gaps must be present in analysis
       - Check fp-cherry-pick: aggregate stats must include min/max/std, not just mean

    5. Full analysis runner:
       - run_full_analysis() -> produces analysis_results.json with ALL above
       - Schema: {meta, per_framework, comparison, anchors, verdict, forbidden_proxy_audit, coverage_gaps, cc014_assessment, cc015_carry_forward}

    Save analysis_results.json to data/xarch/analysis_results.json.
    Use scipy.stats for Clopper-Pearson CI (same as Phase 7 violation_analysis.py).
