  <name>Task 1: Build genuine compaction runner with API integration and dry-run mode</name>
  <files>tools/genuine_compaction_runner.py, tools/test_genuine_compaction_runner.py</files>
  <action>
    Create `tools/genuine_compaction_runner.py` that refactors and extends the existing `compaction_experiment.py`:

    1. **GenuineCompactionRunner class:**
       - `__init__(config: RunnerConfig, ledger: FindingsLedger)` -- Config includes: model, threshold, pause_after_compaction, provenance_aware_instructions, max_retries, output_dir.
       - `run_trial(task_template: TaskTemplate) -> TrialResult` -- Execute one trial:
         a. Initialize clean forge chamber
         b. Build conversation from task template iterations
         c. For each iteration: send to API, register forge artifact, check for compaction
         d. On compaction event (stop_reason == "compaction"):
            - Call `capture_boundary()` to snapshot before/after state
            - Extract summary via `summary_parser.parse_summary_provenance()`
            - Compute artifact_id_survival via `summary_parser.extract_artifact_ids()`
            - Compute SPF via `embedding_similarity.compute_similarity()`
            - Classify refs via `summary_parser.classify_ref_tier()`
            - Append response to messages and continue
         e. After task completion: seal chamber, encode trace, compute final metrics
       - `capture_boundary(messages, compaction_block, chamber) -> CompactionSnapshot` -- Takes before/after snapshots:
         - Pre-snapshot: artifact IDs, ref graph, chamber hash
         - Summary text extraction from compaction block
         - Post-snapshot: surviving IDs, resolved/degraded/broken classification
       - `log_results(trial: TrialResult)` -- Write to JSONL at `data/compaction/genuine/track-{track}-{trial_id}.jsonl`

    2. **Dry-run mode:** When `ANTHROPIC_API_KEY` is not set or `config.dry_run = True`:
       - Use synthetic responses (similar to existing `_run_simulated()` in compaction_experiment.py)
       - Simulate a compaction event at the midpoint
       - Generate synthetic summary text that preserves some artifact IDs and loses others
       - All output is labeled `"mode": "dry-run"` in the JSONL

    3. **API configuration:** Use `compact_20260112` beta via:
       ```python
       context_management={
           "edits": [{
               "type": "compact_20260112",
               "trigger": {"type": "input_tokens", "value": config.threshold},
               "pause_after_compaction": True,
               "instructions": custom_instructions if config.provenance_aware else None,
           }]
       }
       ```
       Where `custom_instructions` is the provenance-aware summarization prompt from the protocol.

    4. **Retry logic:** Max 3 retries on API errors (rate limit, server error). Exponential backoff (2, 4, 8 seconds). Log each retry to findings ledger.

    5. **JSONL schema per trial:**
       ```json
       {
         "trial_id": "track-a-001",
         "track": "A",
         "task_category": "coding",
         "model": "claude-sonnet-4-20250514",
         "mode": "live" | "dry-run",
         "provenance_aware": false,
         "threshold": 80000,
         "compaction_events": [...],
         "aggregate_metrics": {
           "structural_reachability": 0.78,
           "semantic_fidelity": 0.65,
           "artifact_id_survival": 0.60,
           "compression_ratio": 8.5,
           "degraded_fraction": 0.13
         },
         "trace_stats": {...},
         "timestamp": "..."
       }
       ```

    Create `tools/test_genuine_compaction_runner.py` with:
    - Dry-run mode end-to-end test (no API calls)
    - Metric computation validation on known inputs
    - JSONL schema validation
    - Boundary capture logic tests
    - Retry logic tests (mock API errors)
    - At least 10 test functions
  </action>
  <verify>
    1. All tests pass: `python3 -m pytest tools/test_genuine_compaction_runner.py -v`

    3. Metric values in valid ranges: structural_reachability in [0,1], artifact_id_survival in [0,1], compression_ratio > 0
