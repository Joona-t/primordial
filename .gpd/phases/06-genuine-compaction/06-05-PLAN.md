  <name>Task 1: Build statistical analysis pipeline</name>
  <files>tools/compaction_analysis.py, tools/test_compaction_analysis.py</files>
  <action>
    Create `tools/compaction_analysis.py`:

    1. **CompactionAnalysis class:**
       - `__init__(data_dir: str = "data/compaction/genuine/")` -- Load all JSONL result files
       - `load_track_data(track: str) -> list[dict]` -- Parse JSONL for a specific track (A, B, C)

    2. **Primary hypothesis tests (from protocol Section 7.1):**
       - `test_reachability_hypothesis(data: list[dict], threshold: float = 0.5) -> HypothesisResult`:
         - H0: structural_reachability <= threshold
         - H1: structural_reachability > threshold
         - One-sample t-test (scipy.stats.ttest_1samp, alternative='greater')
         - Report: t-statistic, p-value, effect size d = (mean - threshold) / std
         - 95% CI via bootstrap (B=10000, seed=42) or Wilson score if N < 10
       - `test_instruction_delta(data_aware: list, data_default: list) -> HypothesisResult`:
         - H0: delta = survival(aware) - survival(default) <= 0
         - Paired t-test or Wilcoxon signed-rank (if non-normal)
         - Bonferroni-corrected p-value for 3 comparisons
         - Report both corrected and uncorrected p-values

    3. **Confidence intervals:**
       - `bootstrap_ci(values: list[float], B: int = 10000, seed: int = 42, alpha: float = 0.05) -> tuple[float, float]` -- Percentile bootstrap
       - `clopper_pearson_ci(k: int, n: int, alpha: float = 0.05) -> tuple[float, float]` -- Exact binomial for boundary values
       - `wilson_ci(k: int, n: int, alpha: float = 0.05) -> tuple[float, float]` -- For small N interior values

    4. **Anchor comparison framework:**
       - `cross_reference_anchors(metrics: dict) -> AnchorComparison`:
         - MockLM anchor: structural_reachability = 1.0, artifact_id_survival = 1.0 -> compute gap
         - Knowledge Objects: 60% fact loss -> compare artifact_id_survival vs 0.4
         - v1.0 simulated: load from data/compaction/compaction-report.json -> find comparable compression ratio -> compare structural_reachability
         - Return structured comparison dict with pass/fail/partial for each anchor

    5. **Verdict rendering:**
       - `render_verdict(analysis: dict) -> Verdict`:
         - PASS: structural_reachability > 0.5 with p < 0.05
         - PARTIAL: measured but not > 0.5, OR compaction fires but sample too small
         - FAIL: pipeline broke, or compaction never fired
         - BACKTRACK: structural_reachability <= 0.5 under ALL conditions including provenance-aware
         - Include: verdicts for claim-compaction-survival and claim-instruction-effect
         - Include: forbidden proxy audit status

    6. **Cross-track summary:**
       - `summarize_tracks(track_a: list, track_b: list, track_c: list) -> dict`:
         - Per-track: N, mean structural_reachability, CI, compaction_events
         - Cross-track consistency check: are Track A and Track B results compatible?
         - Track C ablation: which factor has largest effect?

    Create `tools/test_compaction_analysis.py` with:
    - CI computation on known data (verify covers true value)
    - Hypothesis test on known data (known rejection/non-rejection)
    - Anchor comparison with known metrics
    - Verdict rendering for each outcome scenario (PASS, PARTIAL, FAIL, BACKTRACK)
    - Cross-track summary aggregation
    - At least 12 test functions
  </action>
