    Core class:
    ```python
    class CampaignRunner:
        def __init__(
            self,
            corpus: AdversarialCorpus,
            output_dir: str = "data/campaign/runs",
            dry_run: bool = False,
            backend: str = "mock",  # "mock" | "openclaw" | "claude-code"
        ):
            ...

        def run_single(
            self,
            task_id: str,
            stress_level: str = "control",
            run_index: int = 0,
        ) -> dict:
            """Execute one run. Returns result dict with all 7 channels."""

        def run_task_battery(
            self,
            task_id: str,
            runs_per_level: int = 3,
        ) -> list[dict]:
            """Run all stress levels for one task."""

        def run_full_campaign(
            self,
            resume_from: str | None = None,
        ) -> dict:
            """Run entire 201-run campaign. Supports resume."""

        def get_campaign_status(self) -> dict:
            """Return progress: completed/total/failed/skipped per task."""
    ```

    Each run result MUST contain all 7 instrumentation channels (RESEARCH Section 5.4):
    ```python
    {
        "run_id": "TASK-A1a_moderate_003",
        "task_id": "TASK-A1a",
        "stress_level": "moderate",
        "run_index": 3,
        "timestamp": "ISO-8601",

        # Channel 1: Forge chamber
        "chamber": {...},  # Complete forge chamber dict

        # Channel 2: Raw LLM transcript
        "transcript": [{"role": "...", "content": "...", "tokens": N}, ...],

        # Channel 3: Tool call log
        "tool_call_log": [{"tool": "...", "call_id": "...", "input": {...}, "output": {...}, "duration_ms": N, "error": null}, ...],

        # Channel 4: Compaction events
        "compaction_events": [{"timestamp": "...", "type": "...", "tokens_before": N, "tokens_after": N}, ...],

        # Channel 5: Token counts
        "token_count": {"per_call": [...], "cumulative": N},

        # Channel 6: Wall clock
        "wall_clock_seconds": float,

        # Channel 7: Framework version
        "framework_version": "openclaw-vX.Y.Z",

        # Meta
        "task_completed": bool,
        "task_success": bool,
        "errors": [...],
    }
    ```

    Dry-run mode (backend="mock"):
    - Uses MockLM to generate synthetic but structurally valid chambers
    - Generates realistic-looking transcripts and tool call logs
    - Used for testing the pipeline end-to-end without real API calls
    - Must produce output in the exact same schema as real runs

    Resume support:
    - Write each completed run to data/campaign/runs/{run_id}.json immediately
    - On resume, scan output_dir for completed runs and skip them
    - Campaign progress stored in data/campaign/campaign_status.json

    Error handling:
    - If a run times out (> 30 min wall clock for LONG, > 60 min for EXTREME): record partial result with "timed_out": true
    - If a run crashes: record error, continue to next run
    - Never abort the full campaign due to individual run failures
