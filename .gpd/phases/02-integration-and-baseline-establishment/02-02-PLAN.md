    Build the adapter class following the PrimordialRLM bridge pattern (tools/primordial_rlm_bridge.py), adapted for the target runtime identified in Plan 02-01.

    The adapter MUST implement these interception points:

    1. PER-TURN REGISTRATION:
       - On each agent iteration/turn: create a forge stage artifact
       - Artifact ID format: artifact:<runtime>:<run_id>:iter:<index>:r1
       - Build source_refs chain: each iteration refs the previous one
       - Assign typed absence state: NOT_GENERATED if LLM produced no output, None otherwise
       - Use create_v1_stage_artifact() and create_v1_stage_summary() from forge_stage_output.py

    2. PER-TOOL-CALL REGISTRATION:
       - On each tool call/subcall: create a forge stage artifact
       - Artifact ID format: artifact:<runtime>:<run_id>:subcall:<index>:r1
       - Build source_ref to parent iteration artifact
       - Assign typed absence state based on tool call result

    3. LLM COMPACTION EVENT DETECTION:
       - Use the approach recommended by Plan 02-01 compaction characterization:
         * If Approach 1 (real-time wrapping): wrap the compaction function directly
         * If Approach 2 (post-hoc JSONL): monitor session transcript for compaction entries
         * If Approach 3 (prompt-layer): detect message history shrinkage
       - Register LLM compaction as artifact with source_refs to ALL compacted iteration artifacts
       - Compaction artifact ID: artifact:<runtime>:<run_id>:compact:<count>:r1

    4. CHAMBER LIFECYCLE:
       - Create chamber at task start: chamber:<runtime>:<run_id>:v1
       - Register each artifact via register_stage()
       - Seal chamber at task completion via seal_chamber()
       - Handle exceptions: seal chamber on error to preserve partial data

    CRITICAL CONSTRAINTS:
    - Do NOT modify any existing forge tool code (forge_nulls.py, forge_chamber.py, etc.)
    - IMPORT from forge tools, do not copy code

    - Follow artifact ID format convention #5 from CONVENTIONS.md
